QA Workbench 웹 링크 만들기 - 5단계

1. GitHub에서 새 저장소 생성 (예: qa-workbench-web)
2. 이 ZIP을 풀고 안의 파일 전체를 GitHub 저장소에 업로드
3. share.streamlit.io 접속 → GitHub 로그인
4. Create app → 저장소 선택 → Main file path에 streamlit_app.py 입력
5. Deploy

완료되면:
https://원하는이름.streamlit.app
형태의 링크가 생깁니다.

필수 파일:
- streamlit_app.py
- requirements.txt
- packages.txt
- qa_web 폴더
- .streamlit/config.toml
